# かんけん4級 道場

漢字検定4級の合格をめざす、iPad 向けの手書き学習 PWA です。
ビルド不要の素の HTML / CSS / JavaScript（ES Modules）で作っています。

## 主な機能

| 機能 | 内容 |
|---|---|
| 手書き判定 | Apple Pencil・指で書いた字を自動で採点。筆圧に対応し、手のひらの誤反応を防ぐ |
| ひらがなも手書き | 読み・送りがなは1マス1字で手書き。小さい「ゃ」「っ」は書いた大きさで見分ける（かなパッド・キーボードにも切りかえ可） |
| 忘却曲線による出題 | 問題ごとに「記憶の安定度」を記録し、記憶の定着度が 90% を下回るころに再出題（FSRS 風のモデル） |
| 苦手の優先出題 | まちがえた問題は同じ回の3問後にもう一度出題。以降も早め・多めに出題 |
| 本番形式の10分野 | 読み／同音・同訓異字／漢字識別／熟語の構成／部首／対義語・類義語／送りがな／四字熟語／誤字訂正／書き取り（オリジナル問題 971問） |
| 模擬試験 | 本番モード（150問・60分・200点）とミニ模試（44問・20分）。中断・再開、目次から移動、提出後に一括採点、合否判定 |
| 模試の見直し | 「模試」ページの「これまでの記録」→「見直す」で、過去の模試の答え合わせをいつでも確認。まちがえた問題だけを練習にできる（手書きの字は最新10回分を保存） |
| 答案用紙モード | 解答欄を本番に近い見た目（白い用紙・黒わくの解答欄・本番ふうの指示文）にし、答え合わせで字ごとの「はね」「はらい」の場所を色分けして表示。「とめ・はね・はらい」のチェックリストで自己採点し、直すところがあれば×にできる（設定で「模試だけ／練習でも／使わない」） |
| 漢字辞典 | 4級配当漢字 314字。書き順アニメーション、音訓・部首・画数、関連語、習熟度の色分け |
| なぞり書き | 1画ごとに書き順・向き・形をチェック（「それは3画目だよ」など） |
| 学習記録 | 合格予想スコア、忘却曲線の予測グラフ、学習カレンダー、分野別の成績、苦手ランキング、模試の推移 |
| やる気の仕組み | XP・レベル・称号、コンボ、バッジ19種、花丸スタンプ、桜吹雪、効果音（Web Audio で合成） |
| 便利機能 | 受検日カウントダウンと1日の目安、苦手ノート（☆）、答えの読み上げ、かなパッド、ダークモード、バックアップ |

## 使い方（iPad）

1. HTTPS で配信されている URL を Safari で開く（下の「公開のしかた」を参照）
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから起動すると、全画面・オフラインで使えます

> 学習記録は端末のブラウザ内（localStorage）に保存されます。Safari の「履歴と Web サイトデータを消去」で消えるため、
> 設定画面の「バックアップを保存」でときどき書き出してください。

## 手書き判定のしくみ

`js/recognizer.js`

1. **オンライン**：Google 手書き入力 API に線の座標を送り、返ってきた候補に正解が含まれるかで判定します（きびしさの設定で「上位何位までを正解にするか」が変わります）
2. **オフライン**：KanjiVG の書き順データと、1画ずつ照合します（ハンガリアン法で画を対応づけ、ストローク数が近い約100字の「ライバル」と比べて順位を出す）。模擬データでは「ふつう」設定での誤判定率は約1%でした
3. **自分で判定**：お手本と見比べて ○／× を自分でつけます

どの方式でも、答え合わせ画面の「判定を修正」で結果を直せます。
「自動」設定では書いた線の座標データが Google に送信されます。送信したくない場合は設定で「端末内のみ」を選んでください。

> 漢検の採点は「とめ・はね・はらい」まで厳密です。自動判定は字の形の大まかな一致しか見ないため、答え合わせのお手本と見比べる習慣をつけましょう。

## 開発

```bash
npm start
```

`http://localhost:8765` で確認できます（Service Worker は localhost か HTTPS でのみ動きます）。

### ファイル構成

```
index.html / manifest.webmanifest / sw.js   PWA の入口・オフラインキャッシュ
css/style.css                                デザイン（和紙×墨×朱、ダークモード）
js/app.js          画面の切りかえ
js/bank.js         問題バンクの読み込み・分野の定義
js/srs.js          忘却曲線・出題スケジューラー
js/recognizer.js   手書き判定（Google／オフライン照合）
js/pad.js          手書きパッド（Pointer Events・筆圧・パームリジェクション）
js/question.js     問題の表示・解答・採点（練習と模試で共通）
js/screens/*.js    ホーム／分野別／練習／模試／辞典／記録／設定
data/questions.js  問題データ（ここを編集すれば問題を追加できます）
data/kanji.js      4級配当漢字の辞典データ（自動生成）
data/strokes.json  書き順データ（自動生成）
tools/build-data.mjs  データ生成・問題の検証スクリプト
```

### 問題を追加・修正する

`data/questions.js` を編集してから、データ生成スクリプトを実行します。
スクリプトは問題を検証し（誤字が文中に1回だけあるか、選択肢に答えがあるか、書き順データがあるか など）、
書き取りの答えに新しい漢字が増えたときは書き順データも追加します。

```bash
curl -LO https://github.com/KanjiVG/kanjivg/releases/download/r20250816/kanjivg-20250816.xml.gz && gunzip kanjivg-20250816.xml.gz
```

```bash
curl -o joyo.txt "https://ja.wikipedia.org/w/index.php?title=%E5%B8%B8%E7%94%A8%E6%BC%A2%E5%AD%97%E4%B8%80%E8%A6%A7&action=raw"
```

```bash
node tools/build-data.mjs kanjivg-20250816.xml joyo.txt
```

問題の ID は問題文から作るハッシュなので、問題文を変えるとその問題の学習記録はリセットされます。

### 公開のしかた

静的ファイルだけなので、GitHub Pages・Netlify・Cloudflare Pages などにフォルダごと置けば動きます（HTTPS が必要）。
ファイルを更新したら `sw.js` の `VERSION` を上げると、アプリ内に「新しいバージョンがあります」と表示されます。

## 注意

- 問題はすべて本番の出題形式にならったオリジナル問題です。過去問の転載ではありません
- 4級配当漢字の一覧（`tools/build-data.mjs` の `LIST4`）は作者がまとめたもので、公式の配当表（313字）と1字ずれています。公式の配当表と照らし合わせて確認してください
- 本アプリは日本漢字能力検定協会とは関係ありません
